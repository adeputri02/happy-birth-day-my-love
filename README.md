# Birthday Love Letter 🤍

Website ucapan ulang tahun romantis dengan:
- Kue ulang tahun dan lilin animasi
- Tombol **Tiup Lilin**
- Surat cinta bernuansa sastra
- Bintang berkelip dan hati melayang
- Tombol audio opsional (nada ambient sederhana)

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu klik **Save**.
6. Tunggu proses selesai; alamat website akan tampil di bagian Pages.

Semua berjalan di browser, tanpa backend atau build step.
